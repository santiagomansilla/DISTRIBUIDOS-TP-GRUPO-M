Este fue un trabajo de la facultad, espero les resulte util como lo fue para mi el poder indagar y conocer como trabajan los sistemas con configuraciones tan heterogéneas y como es posibles integrarlos en entornos tan cambiantes. 

Resulta interesante la capacidad que te da este proyecto al construirlo de cero a 100 por que te permite analizar cada parte del engranaje obteniendo información de cada proceso y/o flujo que interacciona hacia el camino de armar un todo.

Mas técnicamente hablando me permito conocer el uso de Llamadas a procedimientos remotos , como un frontend envía las peticiones a un back , como se estructura un backend y se restringe el acceso a datos.

Además en un primer voceto utilice Rest y grapqhl para trabajar con las peticiones sobre http, posterior a ello migre a grpc y como ultima implementacion use rabbirMQ para trabajar con procesos sinconicos y asincronicos.

Para la persistencia use MariaDB, con la gui de DBeaver (buscaba probar algo diferente al típico mysql que te presentan en la facultad ) por lo menos en mi caso fue bastante amigable.

Obviamente si use IA, pero últimamente intento enfocarme mas en utilizarla como una tool mas que como un copiar y pegar, fue mas un acceso a una fuente de información que me permitió cuestionar por que me daba ciertas solucione y que tan critico puede ser el operador a la hora de respaldarse en ella.
